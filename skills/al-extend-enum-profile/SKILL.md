# Extend an Enum or Profile
Start from [EnumProfileExt.al.template](./templates/EnumProfileExt.al.template).
- Base enum must be Extensible=true. Value IDs from your range; caption values; supply Implementation if the base enum implements an interface. Never renumber. Profile pairs with a pagecustomization.

Full AL grammar (loads on demand): [extension-syntax.md](./reference/extension-syntax.md)
